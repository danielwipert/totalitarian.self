# Excerpts

Pages pulled by hand from copyrighted books (or public-domain PDFs that can't be downloaded automatically). See `../excerpts-needed.md` and `../recent-sources.md` for what to pull.

- One file per work, named like the source files: e.g. `byrne-the-secret.txt`, `doyle-untamed.txt`.
- First lines: author, title, edition (publisher, year), and the pages covered.
- Mark each page break like `[p. 21]`.
- Type or paste the text exactly as printed. Don't fix spelling or wording.
- A public-domain PDF can go in as the PDF itself (e.g. `surgeon-general-loneliness-2023.pdf`).

Never edit a file here after a reader has tagged it; corrections go in `../primary/`.
