# Excerpts needed

> **The master list is now `to-pull.md`**, in pull order with tiers. This file keeps the original notes and is no longer updated.


Works still under copyright that the claims need. These can't be downloaded, so they need excerpts from a copy in hand: a photo, scan or typed transcription of the pages named, with the edition and page numbers.

**How to add an excerpt**

1. Pull the pages listed (or the whole chapter, if it's short).
2. Save them as a text file in `sources/excerpts/`, named like the source files (e.g. `riesman-lonely-crowd.txt`). Put the edition and page numbers at the top, and mark each page break like `[p. 21]`.
3. Tell Claude. A reader will tag the passages in `sources/primary/` exactly as with the other texts.

Chapter titles, terms and page references below marked **verify** are from memory; terms in *italics* are the author's own terms as remembered, not quotations, and need checking in the book itself. Priorities: **1** = decides a claim; **2** = strongly tests a claim; **3** = useful background or secondary check.
